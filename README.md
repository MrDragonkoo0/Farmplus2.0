# Farm+ Mini App UI 1.1

Перенесений у мобільний UI набір основних розділів Farm+:
- головна
- поля
- гараж/техніка
- склад
- тварини
- працівники
- замовлення
- виробництво
- ринок
- завдання
- профіль
- погода та сезон на головній

Це поки фронтенд-прототип. Дані тестові. Наступний етап — підключення до реального Farm+ backend/API та авторизації Telegram.
